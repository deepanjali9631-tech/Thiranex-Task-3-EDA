# Exploratory Data Analysis – E-Commerce Dataset

## Project Overview

This project is completed as **Task 3 of the Thiranex Internship Program**.

The objective is to perform **Exploratory Data Analysis (EDA)** on an e-commerce dataset to identify patterns, trends, relationships, and important business insights.

## Objectives

* Understand and clean the dataset
* Perform statistical analysis
* Analyze customer and product behavior
* Identify sales and revenue trends
* Study correlations between numerical variables
* Create meaningful visualizations
* Extract key insights from the data

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The project uses the **Online Retail Dataset**, containing transaction information such as:

* Invoice Number
* Product Description
* Quantity
* Invoice Date
* Unit Price
* Customer ID
* Country

A **Revenue** feature was created using:

`Revenue = Quantity × UnitPrice`

## EDA Performed

* Data cleaning and preprocessing
* Missing value analysis
* Duplicate analysis
* Statistical summary
* Distribution analysis
* Outlier detection
* Product analysis
* Customer analysis
* Country-wise analysis
* Monthly revenue analysis
* Correlation analysis
* Correlation heatmap
* Scatter plots

## Key Insights

The analysis helps identify:

* Top-performing products
* High-value customers
* High-revenue countries
* Sales and revenue trends
* Customer purchasing patterns
* Relationships between quantity, price, and revenue

## Conclusion

This project demonstrates the complete EDA process, from data cleaning and statistical analysis to visualization and insight generation. It helped develop practical skills in **data analysis, visualization, and analytical thinking**.
